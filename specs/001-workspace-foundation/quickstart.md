| Visual Studio Build Tools | 2019+ with C++ workload | Windows builds |

## Environment Setup

### 1. Install Serverpod CLI

```bash
dart pub global activate serverpod_cli
```

### 2. Create Serverpod Project

```bash
serverpod create motaz_app
```

This generates:
- `motaz_app_server/` — backend
- `motaz_app_client/` — generated client library
- `motaz_app_flutter/` — Flutter integration package
- `motaz_app/` — Flutter app (NOT auto-generated by serverpod, created manually or via `flutter create`)

### 3. Configure Neon PostgreSQL

Edit `motaz_app_server/config/development.yaml`:
```yaml
database:
  host: <neon-host>
  port: 5432
  name: motaz_app_dev
  user: <neon-user>
  password: <from passwords.yaml>
  requireSsl: true
```

Create `motaz_app_server/config/passwords.yaml` (gitignored):
```yaml
development:
  database: <neon-password>
```

### 4. Add Dependencies to Flutter App

In `motaz_app/pubspec.yaml`:
```yaml
dependencies:
  flutter:
    sdk: flutter
  flutter_localizations:
    sdk: flutter
  flutter_riverpod: ^2.0.0
  riverpod_annotation: ^2.0.0
  drift: ^2.0.0
  sqlite3_flutter_libs: ^0.5.0
  path_provider: ^2.0.0
  path: ^1.8.0
  connectivity_plus: ^6.0.0
  go_router: ^14.0.0
  uuid: ^4.0.0
  serverpod_auth_email_flutter: ^2.0.0
  motaz_app_client:
    path: ../motaz_app_client
  motaz_app_flutter:
    path: ../motaz_app_flutter

dev_dependencies:
  flutter_test:
    sdk: flutter
  drift_dev: ^2.0.0
  build_runner: ^2.0.0
  riverpod_generator: ^2.0.0
```

### 5. Run Code Generation

```bash
# Generate Drift database code
cd motaz_app
dart run build_runner build --delete-conflicting-outputs

# Generate Serverpod protocol classes
cd ../motaz_app_server
serverpod generate
```

## Running the App

### Backend

```bash
cd motaz_app_server
dart run bin/main.dart
```

### Flutter App (Android)

```bash
cd motaz_app
flutter run -d <android-device>
```

### Flutter App (Windows)

```bash
cd motaz_app
flutter run -d windows
```
